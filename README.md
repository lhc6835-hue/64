# 6개장 4발면 🍜 (6학년 4반 전용 사이트)

크롬북에서 바로 쓰는 우리 반 교실 도구 모음입니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 번호 뽑기 | 숫자가 돌다가 멈추는 연출로 1~5명 뽑기, 뽑힌 번호 빼기 |
| 자리 뽑기 | 한 자리씩 두구두구 공개, 옆자리 짝 남녀 맞추기, 확정하면 모두에게 공유 |
| 타이머 | ±1분/±10초, 경고음 켜기·끄기, 1분 전 알림, 마지막 10초 소리 |
| 게시물 | 선생님이 올린 링크를 눌러 바로 들어가기 |
| 모둠 뽑기 | 원하는 모둠 수로 공평하게 나누기 |
| 소음 측정 | 마이크로 재는 소음 신호등 |
| 알림장 | 첫 화면에 보이는 오늘의 알림 |

## 구조

- `index.html`, `css/`, `js/` — 사이트 본체 (설치·빌드 없이 그대로 동작, GitHub Pages로 배포)
- `worker/worker.js` — 게시물·알림장·자리표·반 설정을 저장하는 Cloudflare Worker (KV 저장)

게시물·알림장·설정은 오른쪽 위 **🔒 선생님** 버튼으로 비밀번호를 입력한 뒤에만 바꿀 수 있습니다.
비밀번호는 서버에 해시로만 저장되며 이 저장소에는 들어 있지 않습니다.
학생 이름 같은 개인정보는 다루지 않고 번호만 사용합니다.
