# 6개장 4발면 (6학년 4반 전용 사이트)

크롬북에서 바로 쓰는 우리 반 교실 도구 모음입니다. 화면은 전부 픽셀 아트이고, 그림 파일 없이 코드로 그립니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 번호 뽑기 | 캡슐 뽑기 기계에서 캡슐이 굴러 나와 터지며 번호 공개. 1~5명, 뽑힌 번호 빼기 |
| 자리 뽑기 | 픽셀 교실에서 조명이 돌다가 한 자리씩 공개. 옆자리 짝 남녀 맞추기, 확정하면 모두에게 공유 |
| 타이머 | 도화선이 타들어 가다 시간이 끝나면 불꽃놀이. ±1분/±10초, 경고음 켜기·끄기 |
| 게시물 | 선생님이 올린 링크를 눌러 바로 들어가기 |
| 모둠 뽑기 | 원하는 모둠 수로 공평하게 나누기 |
| 소음 측정 | 시끄러울수록 끓어 넘치는 라면 냄비와 소음 신호등 |
| 알림장 | 첫 화면에 보이는 오늘의 알림 |

## 구조

- `index.html`, `css/`, `js/` — 사이트 본체 (설치·빌드 없이 그대로 동작, GitHub Pages로 배포)
- `js/scenes/` — 화면마다의 픽셀 장면 (첫 화면 풍경, 캡슐 기계, 교실, 도화선, 냄비)
- `js/fx/` — 직접 만든 이펙트 (캡슐 터짐, 뿅 하고 나타남, 불꽃놀이)
- `js/art.js` — 버튼·패널 테두리와 아이콘을 코드로 그리는 곳
- `worker/worker.js` — 게시물·알림장·자리표·반 설정을 저장하는 Cloudflare Worker (KV 저장)

게시물·알림장·설정은 오른쪽 위 자물쇠(선생님) 버튼으로 비밀번호를 입력한 뒤에만 바꿀 수 있습니다.
비밀번호는 서버에 해시로만 저장되며 이 저장소에는 들어 있지 않습니다.
학생 이름 같은 개인정보는 다루지 않고 번호만 사용합니다.

## 가져다 쓴 것

- `js/pixelfx/` — [pixelfx](https://github.com/patch-gg/pixelfx) 의 코어 엔진 일부 (MIT, `js/pixelfx/LICENSE`·`NOTICE.md` 참고).
  pixelfx 에 들어 있는 기존 이펙트는 쓰지 않았고, 이 사이트의 장면과 이펙트는 그 엔진 위에서 새로 만들었습니다.
- `fonts/` — [Galmuri](https://github.com/quiple/galmuri) 픽셀 글꼴 (SIL OFL 1.1, `fonts/LICENSE.txt`)
